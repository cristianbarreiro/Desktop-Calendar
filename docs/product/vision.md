# Product Vision

## Desktop Calendar Widget

A modern, lightweight Windows desktop calendar application that provides two connected experiences:

### Widget (Primary)

A compact, always-accessible desktop calendar for quick date checking and event viewing. The widget is the daily-use experience — minimal, fast, and unobtrusive.

### Full Application (Management)

A window-based application for managing calendar events, notes, and settings. Opened from the widget when the user needs the full management experience.

## Core Principles

- **Minimal** — Only the features that provide clear value
- **Fast** — Instant startup, no loading screens
- **Lightweight** — Low memory footprint, low CPU usage
- **Modern** — Contemporary Windows design language
- **Elegant** — Intentional visual design, no visual noise
- **Keyboard-friendly** — Full keyboard navigation
- **Mouse-friendly** — Intuitive click/hover interactions
- **Accessible** — Keyboard nav, contrast, focus states
- **Offline-first** — Works entirely without network
- **Privacy-oriented** — No telemetry, no cloud by default
- **Local-first** — Data stored locally in SQLite
- **Extensible** — Architecture supports future features
- **Maintainable** — Clean layered architecture

## What This Product Is NOT

- Not a full-featured calendar suite (Outlook, Google Calendar)
- Not a project management tool
- Not a cloud-synced collaboration platform
- Not a mobile application
- Not an Electron/web wrapper

The product should feel like a native modern Windows productivity utility.
