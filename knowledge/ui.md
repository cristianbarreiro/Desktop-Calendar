# UI & UX Knowledge

## Two Experiences, One Application

### Experience A: The Desktop Widget
- **Role**: Quick-glance desk calendar.
- **Form factor**: Compact (approx. 280x240px when collapsed, expands to ~360px when a day is selected).
- **Placement**: Stays on the desktop, optional "Always on top".
- **Primary actions**: Click days to see events, glance at time/date, switch to full app.

### Experience B: The Full Application
- **Role**: Complete management center.
- **Form factor**: Standard resizable Windows window (default 900x600px).
- **Sections**:
  1. Calendar (Expanded month grid + event creation dialogs).
  2. Notes (List + editor).
  3. Settings (Appearance, system integrations, backup/restore).

## Design Tokens
- Typography: Segoe UI Variable.
- Themes: Dark (primary) and Light.
- Accent: Modern Windows Blue (`#0078D4`).
- Motion: Snappy, purposeful micro-animations (< 200ms) with reduced-motion support.
